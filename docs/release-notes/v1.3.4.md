# Codex Auth Switch v1.3.4

> 新增实验室，将本地 Codex 登录作为可选实验功能，支持授权后先保存账号、再主动切换。

## 新功能

- 侧边栏新增“实验室”，与“设置”相邻。实验功能默认关闭，开关仅保存在本机，重启应用后保留。
- 在实验室启用“本地 Codex 登录”后，“登录新账号”可选择本地 Codex 或 OAuth 设备码登录，并为实验选项显示明确标记。
- 本地 Codex 登录调用已安装的 Codex 运行时完成浏览器授权，支持重新打开浏览器、复制授权链接、取消和超时处理。
- 本地登录成功后先保存到账号库，可立即选择切换，也可稍后从账号列表切换；已有 OAuth 设备码登录继续保留。

## 凭据与会话保护

- 本地 Codex 登录使用独立临时目录，在主动切换前保持当前认证和存储设置不变。
- 同一账号重新登录后标记为“新登录待切换”，避免当前客户端旧会话及额度、迁移刷新覆盖或隐式激活新登录。
- 处理提前到达或重复的登录通知，以及取消与保存同时发生的情况；正常完成、取消、失败和退出时清理本次进程与临时目录。
- 认证令牌和完整授权地址保留在后端，不传入前端状态或错误日志。

## 升级提醒

- 本版本兼容已有账号库，无需手动迁移。关闭实验功能不会删除已保存的账号。
- 本地 Codex 登录仍为实验性功能，需要可用且支持该方式的 Codex 运行时。已完成 macOS 初始化与合成数据测试，真实授权和 Windows/Linux 登录流程仍待人工验证；遇到兼容问题可继续使用 OAuth 设备码登录。
- 继续保持纯本地账号管理，不新增遥测或后端服务；自主实现保持 MIT 许可，未引入 Cockpit 源码或捆绑 Codex 运行时。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
