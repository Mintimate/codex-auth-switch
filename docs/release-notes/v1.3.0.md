# Codex Auth Switch v1.3.0

> 切换已保存账号时可同步重启 Codex 桌面客户端，并精简账号卡片的操作布局。

## 重点内容

- 新增“仅切换”和“切换并重启”两种方式，默认每次询问。可勾选记住选择，并在“设置 → 已保存账号切换方式”中调整。
- 选择重启后，先验证目标账号与客户端，再请求正常退出；确认退出后保存旧账号最新凭据、原子替换认证文件，最后重新打开原客户端。
- 切换按钮采用双向箭头图标加“切换”文字。迁移、重命名和移除改用带悬停说明的图标按钮，操作栏独立占据一行，减少窄窗口中的挤压与换行。

## 切换反馈

- 展示检查客户端、等待退出、写入账号和重新启动等阶段，切换期间禁用重复操作。
- 退出超时或无法确认客户端身份时停止操作，不强制结束客户端，也不写入新账号。
- 账号已切换但客户端启动失败时，单独提示手动打开；客户端原本未运行时只切换账号，不自动启动。
- 按钮仅在切换期间播放图标动画，文字保持稳定，并尊重系统的减少动态效果设置。

## 升级提醒

- 自动重启支持 macOS 和可识别为 OpenAI Codex 的 Windows 桌面客户端。Linux、自定义 `CODEX_HOME`、多个桌面实例或无法确认身份的客户端，请选择“仅切换”后手动重启。
- 重启可能中断任务，请先结束正在执行的任务。此功能针对桌面客户端，不结束独立 CLI 或 IDE 会话。
- 切换偏好仅作用于已保存账号；新账号登录和 Auth 导入仍需手动重启。
- 自动重启属于本工具的本地兼容实现，不是官方保证的账号切换接口。
- 本版本无需迁移账号数据，继续保持纯本地运行，不新增遥测或后端服务。

## 下载与安装

- 支持应用内更新，也可下载对应平台安装包覆盖安装。
- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
