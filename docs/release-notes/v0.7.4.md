# Codex Auth Switch v0.7.4

> 修复 GitHub 更新包在网络较慢时容易下载超时的问题，并让更新失败提示更准确。

## 重点内容

- **更新检查与安装包下载使用不同超时**。更新清单仍在 30 秒内快速响应，实际安装包下载允许最多 30 分钟，避免 GitHub Release 资产经过重定向 CDN 时因下载较慢而被提前终止。
- **区分检查失败和安装失败**。下载安装包失败时不再错误显示“检查更新失败”，便于判断问题发生在哪个阶段。
- **提供 CNB 备用提示**。GitHub 下载失败时，界面会提示切换到 CNB 更新源后重试。

## 变更内容

### 修复

- 修复 GitHub 更新包共用 30 秒请求超时导致慢速网络下载失败
- 修复下载安装失败被错误标记为检查更新失败
- GitHub 安装失败时显示切换 CNB 的重试建议

## 升级提醒

- 本次仅调整应用内更新流程，不改变账号数据、认证文件或用量统计格式。
- GitHub 与 CNB 仍提供相同的签名更新包，安装前继续由 Tauri 校验更新签名。
- 若当前版本从 GitHub 更新仍然失败，可先选择 CNB 完成本次升级；升级到 v0.7.4 后 GitHub 慢速下载将获得更长等待时间。

## 下载与安装

请按操作系统和处理器架构选择安装包：

| 平台 | 架构 | 推荐安装包 |
| --- | --- | --- |
| macOS | Apple Silicon | `Codex-Auth-Switch_0.7.4_macOS_arm64.dmg` |
| macOS | Intel | `Codex-Auth-Switch_0.7.4_macOS_x64.dmg` |
| Windows | x64 | `Codex-Auth-Switch_0.7.4_Windows_x64-setup.exe`（推荐）或 `Codex-Auth-Switch_0.7.4_Windows_x64.msi` |
| Linux | x64 | `Codex-Auth-Switch_0.7.4_Linux_x64.AppImage`、`Codex-Auth-Switch_0.7.4_Linux_x64.deb` 或 `Codex-Auth-Switch_0.7.4_Linux_x64.rpm` |

> `.app.tar.gz`、`.sig` 和 `latest.json` 由应用内更新使用，手动安装时无需下载。
