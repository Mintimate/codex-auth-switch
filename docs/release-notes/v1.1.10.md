# Codex Auth Switch v1.1.10

> 在订阅额度中新增默认折叠的用量价值模拟，按参考模型价格比较不同缓存假设下的美元估算。

## 重点内容

- 订阅额度页面新增用量价值模拟，默认折叠，感兴趣时可展开查看。
- 使用账号每日用量汇总近 7 天和近 30 天的 Token 总量，支持全部账号或单个账号查看。
- 选择参考模型、调整输入 Token 占比，即可比较无缓存与输入 Token 缓存命中 90% 两种情景下的美元估算。
- 内置模型价格快照，可手动从 OpenAI 公开价格文档更新；更新后的价格保存在本地，离线时仍可使用。

## 统计与可靠性

- 同一订阅的多个本地档案不会重复计入汇总，缺失用量或缓存价格时显示不可估算，并标明数据覆盖范围。
- 价格刷新失败时继续使用已有快照，并提示当前价格来源与更新时间。
- 补充价格解析、缓存读取、估算公式与边界条件测试。

## 升级提醒

- 本版本无需迁移账号数据，继续保持纯本地运行，不新增遥测或后端服务。价格更新仅请求公开文档，不上传账号凭据或用量。
- 每日用量按 UTC 日期统计。估算中的参考模型、输入占比和缓存命中率均为假设，不代表实际使用模型、订阅收费或 API 账单。
- 模拟采用当前标准短上下文单价，不包含长上下文、快速模式、缓存写入、工具调用、税费及折扣。
- 额度查询继续通过 Codex App Server 与 ChatGPT 兼容性层实现，不将这些端点视为有稳定性保证的公开 API。

## 下载与安装

- 支持应用内更新，也可下载对应平台安装包覆盖安装。
- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
