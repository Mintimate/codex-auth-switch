# Codex Auth Switch v0.7.3

> 优化 Token 用量页的加载性能：多账号额度查询改为并发，本地会话扫描不再阻塞界面。

## 重点内容

- **多账号额度查询从串行改为并发**。此前逐个账号排队查询，账号数为 N 时最坏要等 N × 10 秒；期间整个应用的操作被锁住，切换账号、保存登录都点不动。现在最多 4 个并发，等待时间大幅下降。
- **本地会话扫描让出后台线程**。扫描 `sessions` 目录并逐行解析 JSONL 的工作移到专门的阻塞线程池，会话文件多的时候界面不再卡顿。
- **登录与额度查询复用网络连接**。设备登录轮询每 5–8 秒一次，此前每次都重新做 DNS + TCP + TLS 握手，现在连接得以复用。
- **二维码导入改用 base64 传输**。12MB 的图片此前会展开成千万级 JSON 数组元素，序列化和解析的开销远超传输本身。

## 变更内容

### 优化与调整

- 多账号额度查询改为并发执行，用信号量限制为 4 个同时请求，避免账号多时打爆连接池
- 本地会话用量扫描包进阻塞线程池，不再占用 async 工作线程
- reqwest 客户端改为单例复用，OAuth 与额度查询各用一个，以保留各自不同的超时策略
- 二维码导入由 `number[]` 改为 base64 字符串过 IPC，前端分块编码避免调用栈溢出

### 工程与文档

- 新增版本号同步脚本，`npm run bump <version>` 与 `npm run release <version>` 一条命令同步五处版本号
- 移除 45 个未使用的移动端与商店图标（项目不含移动端，也不发布到 Windows Store）
- 应用图标移入 `docs/images/`，减少仓库根目录噪音
- 补充发布流程说明到 AGENTS.md 与两份 README

## 升级提醒

- 已安装用户可直接使用应用内更新，并在设置中选择 GitHub 或 CNB 更新源。
- 本次仅为性能优化，账号数据、凭据文件格式与界面操作均无变化，无需任何手动迁移。
- macOS 安装包目前使用 ad-hoc 签名。若首次启动被系统拦截，请前往“系统设置 → 隐私与安全性”确认打开。
