# Codex Auth Switch v0.8.7

> 新增由 Rust 驱动的本地环境体检，并修复账号页字重与额度动画切页抖动。

## 重点内容

- 设置页新增“本地环境体检”，只读校验 Codex 配置、当前认证、文件权限、账号库、切换历史与原子写残留。
- 诊断结果仅向前端返回状态码、计数和检查时间，不返回令牌、账号 ID、文件路径或原始文件内容。
- 账号页头部卡片改用更舒适的中等字重。

## 变更内容

### 新功能

- 新增 Rust 本地诊断模块，覆盖 8 类环境与数据一致性检查。
- 设置页进入时自动运行体检，并支持手动重新检查。
- 新增中英文诊断说明、状态汇总与响应式明细布局。

### 修复

- 修复账号页当前登录信息和操作标题字重过粗的问题。
- 修复从订阅额度页切换离开再返回时，刷新状态改变动画时长导致进度路线跳动的问题。

### 安全与质量

- 诊断文件读取设有大小上限，未知存储模式不会原样进入前端。
- Unix 平台会检查认证文件及其目录是否存在权限过宽或符号链接风险。
- 前端格式化、类型检查、生产构建、Clippy 和 34 项 Rust 测试均已通过。

## 升级提醒

- 本版本不改变本地账号库格式，无需手动迁移数据。
- 环境体检是只读功能，不会自动修改或删除本机文件。

## 下载与安装

- macOS：根据设备选择 Apple Silicon 或 Intel 安装包。
- Windows：下载对应架构的安装包。
- Linux：下载 AppImage、Deb 或 RPM 包。
- 请仅从 GitHub Releases 或项目提供的 CNB 镜像获取安装包。
