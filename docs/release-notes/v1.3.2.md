# Codex Auth Switch v1.3.2

> 首页新增账号剩余额度摘要，并收紧登录操作区与切换说明，让账号信息更清晰。

## 新功能

- 已保存账号旁直接展示剩余额度百分比与进度条，按账号实际返回的额度窗口显示。
- 点击额度摘要可展开重置时间、模型额度、可用重置次数及查询时间，并单独刷新该账号。
- 首页额度查询遵循“进入页面时自动刷新”设置，也支持手动刷新。

## 界面优化

- 压缩当前登录区域，账号信息与常用操作并排展示，首次添加账号说明默认折叠。
- 保留小猫切换动画和三步提示，将详细切换原理收进折叠说明，减少重复内容。
- 为账号摘要与操作栏统一预留高度，解决单窗口与双窗口账号卡片高低不齐的问题。
- 适配中英文、明暗主题及窄窗口；展开额度详情时，相邻卡片保持原有高度。

## 数据展示

- 区分尚未查询、查询失败、暂无额度窗口与实际额度耗尽，缺失数据不会显示成 0%。
- 优先展示 Codex 默认额度，其他模型额度保留名称，避免混淆不同额度池。
- 刷新失败时保留上次成功结果，并显示缓存与错误提示。

## 升级提醒

- 本版本无需迁移账号数据，支持应用内更新或下载安装包覆盖安装。
- 继续保持纯本地账号管理，不新增遥测或后端服务。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
