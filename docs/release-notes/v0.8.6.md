# Codex Auth Switch v0.8.6

> 为订阅额度加入猫咪巡检动效，并收紧一次性迁移的账号身份校验。

## 重点内容

- 订阅额度页新增“额度补给路线”，动态展示当前账号、窗口使用率、最近恢复时间与完整重置次数。
- 刷新额度时，猫咪会加速巡检各状态节点；恢复时间轴会标记最近事件。
- 拆分应用外壳、账号页面与认证弹窗，降低主组件复杂度并改善后续维护体验。

## 变更内容

### 新功能

- 新增额度巡检场景，并根据充足、注意、紧张状态调整视觉反馈。
- 新增中英文额度场景说明，并完整支持系统“减少动态效果”设置。

### 修复

- 修复设置页快速切换时可能残留应用更新事件监听的问题。
- 修复打包应用中“打开 Codex 目录”可能受权限配置限制的问题。
- CAS3 导入现在必须从刷新结果重新确认账号身份，无法确认时拒绝写入。
- 旧版 CAS2 内容导入前会先刷新凭据并校验账号身份，避免陈旧或错配身份覆盖本地账号。
- 读取 Token 用量和订阅额度时，仅在凭据或激活记录实际变化后写入本地账号库。

### 优化

- 清理未使用的样式与双语文案。
- 简化主题同步逻辑与重复的数据刷新流程。
- 严格 Clippy、前端类型检查、生产构建和 29 项 Rust 测试均已通过。

## 升级提醒

- 旧版 CAS2 迁移内容仍可导入，但现在需要联网刷新并验证账号身份。
- 本版本不改变本地账号库格式，无需手动迁移数据。

## 下载与安装

- macOS：根据设备选择 Apple Silicon 或 Intel 安装包。
- Windows：下载对应架构的安装包。
- Linux：下载 AppImage、Deb 或 RPM 包。
- 请仅从 GitHub Releases 或项目提供的 CNB 镜像获取安装包。
