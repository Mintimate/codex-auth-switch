# Codex Auth Switch v1.3.5

> 订阅额度支持后台自动刷新和本地变化记录，新增双模型费用对比，并改进账号切换反馈与设置布局。

## 新功能

- **后台自动刷新额度**：应用启动后查询一次，之后每 15 分钟更新已保存账号。定时任务由 Rust 执行，无需停留在额度页，隐藏、最小化或重载窗口也可继续运行；设置中提供统一开关，各页面仍支持手动刷新。
- **额度变化记录**：在订阅额度的账号行或账号详情中，查看近 24 小时、7 天和 30 天的趋势与明细。只记录成功查询实际返回的窗口数据，跨周期、来源或套餐变化时断开趋势线，缺失数据不会记为零。
- **双模型费用对比**：订阅价值模拟可选择参考模型 A 和对比模型 B，以相同 Token 用量、输入占比和缓存比例展示近 7 / 30 天费用、金额差额与百分比。支持交换模型、展开费用明细，并保留单模型模拟。
- **紧凑切换反馈**：账号切换后显示本次操作与重启结果，展开详情可核对本机认证文件和桌面进程状态，并支持重新检测。

## 修复与改进

- 手动与后台额度查询共用调度和并发控制，查询失败后延后重试并保留上次成功结果，避免旧响应覆盖新状态；系统休眠恢复后不补跑错过的刷新轮次。
- 历史记录保存失败单独提示，不撤销已成功的额度查询或凭据刷新。历史损坏或清理失败也不再阻止移除账号，原文件保留供用户后续清理。
- 设置页将网络代理和用量额度卡片放入同一列，减少宽屏留白；更新源选择与品牌图标展示统一，并增加对应 Releases 入口。
- 抽离额度模型、原子文件存储、刷新状态 Hook 和费用结果组件，降低账号管理、历史记录与界面的耦合。

## 升级提醒

- 无需手动迁移已有账号库。首次启动会迁移旧版自动刷新偏好，已关闭自动刷新的用户继续保持关闭；退出应用后停止刷新，关闭开关不取消已经发出的查询。
- 额度历史仅保存在本机，最多保留近 30 天、总计 12,000 个窗口观测值、每账号 2,000 个，文件上限 8 MiB；达到上限时淘汰最旧记录。可在变化记录中清空历史，账号与凭据不受影响。
- 切换检查只读取本机文件和进程状态，不联网、不触发登录或重启。桌面客户端正在运行或重启成功，不等于已确认客户端内的登录身份。
- 模型费用对比使用相同用量下的参考 API 单价，仍为情景模拟，不代表实际账单、任务效果或两个模型的真实 Token 消耗相同。缺失价格或用量时不计算对应差额；基准费用为零时不计算百分比。
- 继续保持纯本地账号管理，不新增遥测或后端服务；额度读取沿用现有兼容层。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
