# Codex Auth Switch v1.1.2

> 新增单账号额度刷新和有容量限制的本地用量缓存，改善查询体验，并修复认证与账号切换的一致性问题。

## 重点内容

- 额度页支持单独刷新账号，批量查询逐项显示结果；刷新失败保留上次成功数据。
- 不同账号最多并发查询 2 个，同账号查询串行执行，避免重复使用轮换中的凭据。
- 本地 Token 用量支持 `file`、`auto` 和 `keyring` 凭据模式，无需迁移凭据。
- 设置页新增缓存占用显示和“清理缓存”按钮。

## 变更内容

### 用量与缓存

- 未变更会话复用缓存，追加会话只解析新增完整行；支持文件截断、替换、删除和损坏缓存重建。
- 压缩后的用量缓存最多 8 MiB，只保留近 35 天的统计事件。容量不足时淘汰较旧文件的缓存，不影响当前完整统计。
- 启动或访问缓存时清理超过 7 天未更新的缓存和旧版缓存。
- 清理缓存不删除账号、认证数据或 Codex 会话文件，下次刷新按需重建。
- 缓存仅保存统计与文件校验信息，不保存提示词、回复正文或认证令牌。

### 认证与一致性修复

- 查询失败时仍保存已轮换的凭据，避免后续查询继续使用失效令牌。
- 登录取消后阻止迟到的授权结果写入账号库，并防止重复轮询提交。
- 自动同步不再重新添加已移除的账号。
- 修复切换失败时误记激活历史，以及切换中断恢复后用量归属错误的问题。
- 改善认证文件的原子替换与异常恢复，并避免解析错误包含原始配置或认证内容。

## 升级提醒

- 可通过应用内更新升级，也可下载对应平台的安装包覆盖安装。
- 账号保存、切换和订阅额度查询仍要求文件凭据模式；本地 Token 用量不受此限制。
- 历史用量的账号归属仍依赖本机记录的切换历史，本地 Token 数字不等于订阅总额度。
- 订阅数据的兼容接口保持隔离，不应视为稳定公开 API。应用继续保持纯本地运行。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG 安装包。
- Windows：选择 x64 EXE 或 MSI 安装包。
- Linux：选择 x64 AppImage、Deb 或 RPM 安装包。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
