# Codex Auth Switch v1.1.3

> 新增网络代理设置，支持直连、跟随系统和手动配置 HTTP(S) 代理。

## 重点内容

- 设置页新增「网络代理」，支持代理地址和不使用代理的主机列表。
- 代理设置对登录、凭据刷新、在线额度与用量查询生效，并同步到 Codex 子进程。
- 修改自动保存；保存失败保留草稿并提供重试，重新打开设置页会等待此前保存完成。

## 修复与可靠性

- 修复配置加载覆盖用户编辑、切换页面丢失待保存修改，以及旧客户端缓存导致代理切换不生效的问题。
- 配置损坏或不可读时保留原文件并暂停相关请求，应用仍可启动；修复文件后重新打开设置页即可恢复读取。
- 配置读写在后台执行，避免磁盘操作阻塞界面；补齐代理错误的英文提示。
- 增加直连、手动代理、绕过规则及子进程代理配置测试。

## 下载与安装

- 支持应用内更新，也可下载对应平台安装包覆盖安装。
- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
