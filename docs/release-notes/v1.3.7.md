# Codex Auth Switch v1.3.7

> 新增本机诊断日志，方便排查登录和额度刷新问题，并补全在线预览的 favicon。

## 新功能

- **诊断日志**：在“实验室 → 诊断日志”启用收集后，可查看登录和额度查询的请求结果、耗时、代理模式及脱敏响应；同一轮操作通过查询组号关联，方便对照查询、重试和凭据刷新过程。
- **筛选、导出与清空**：支持仅看异常、展开响应详情、导出 JSON 和清空日志。导出包含全部保留记录，不受异常筛选影响。

## 修复与改进

- 在线预览新增多尺寸 `favicon.ico`，兼容读取默认图标路径的浏览器和站点服务，同时保留 SVG 图标的深浅色适配。
- 完善界面预览、下载入口以及诊断日志的使用说明。

## 使用提醒

- 诊断收集默认关闭，仅对本次运行生效，重启后自动关闭；日志仅保存在本机，不会自动上传。
- 只保留白名单诊断字段，不记录认证头、Cookie、令牌、验证码、账号 ID、邮箱或原始错误文本。服务端消息仅转换为预设分类，不能单凭分类确定故障原因。
- 日志最多保留最近 7 天、500 条、1 MiB。关闭收集会保留历史；清空会同时删除应用生成的导出文件，已在途请求不会重新写回。
- 公开在线演示不能启用诊断收集或导出。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
