# Codex Auth Switch v1.3.3

> 首页新增账号详情批量展开与收起，并统一分区标题和工具栏对齐。

## 新功能

- 已保存账号区域新增“全部展开／全部收起”图标按钮，可一次查看或收起全部账号的额度详情。
- 各账号支持独立展开与收起；部分账号收起后，批量按钮可重新展开全部账号。
- 刷新按钮改为图标，查询时显示旋转状态，保留悬停提示与键盘操作支持。

## 界面优化

- 统一“账号如何切换”和“已保存账号”的标题字号、字重、行高及区域内边距。
- 移除重复的“本机账号库”小标题，标题、动画与账号列表左边缘对齐，工具栏与标题居中对齐。
- 全部展开详情时，同一行账号卡片保持等高；单独展开时，相邻未展开卡片保持紧凑。
- 保留刷新前的账号详情展开状态，并适配中英文、明暗主题和窄窗口。

## 升级提醒

- 本版本无需迁移账号数据，支持应用内更新或下载安装包覆盖安装。
- 继续保持纯本地账号管理，不新增遥测或后端服务。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
