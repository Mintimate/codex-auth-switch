# Codex Auth Switch v1.2.0

> 订阅价值模拟拥有独立页面，并统一界面字体层级，改善窄窗口下的阅读与操作体验。

## 重点内容

- 侧栏新增独立的“订阅价值模拟”入口，进入后直接展示估算控件，也可在设置中将其设为默认启动页。
- 模拟页面可分别刷新账号用量和模型价格。账号用量复用订阅额度的数据源，无需先打开订阅额度页；首次查询失败时显示错误提示并提供重试操作。
- 统一辅助文字、正文、控件、标题和统计数字的字号层级，提高用量明细、额度列表及费用说明的可读性。
- 改善账号与模型选择框、设置页、弹窗和额度表格的响应布局，减少窄窗口下的文字挤压与内容溢出。

## 界面与布局

- 模拟页面的账号、模型选择框采用至少 46px 的高度，并根据可用空间调整控件与金额卡片的排列。
- 字号、字重和行高统一使用语义变量，字号以 `rem` 定义；新增字体规范，明确正文、辅助信息、图表刻度和装饰动画的适用范围。
- 保留数据表格必要的横向滚动，优化长文本、按钮组和弹窗的换行与间距，让较窄窗口中的信息仍可完整查看。
- 继续保留现有任务场景预设、输入与缓存比例调节、普通输入／缓存输入／输出费用拆分及近 7 天、近 30 天估算。

## 升级提醒

- 本版本无需迁移账号数据，继续保持纯本地运行，不新增遥测或后端服务。价格更新仅请求公开文档，不上传账号凭据或用量。
- 账号每日用量仍只有 Token 总数。参考模型、输入占比和输入缓存比例均为模拟假设，结果不代表实际订阅收费或 API 账单。
- 用量汇总按包含今天的 UTC 自然日计算。模拟采用当前标准短上下文单价，不包含长上下文、快速模式、缓存写入、工具调用、税费及折扣。

## 下载与安装

- 支持应用内更新，也可下载对应平台安装包覆盖安装。
- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
