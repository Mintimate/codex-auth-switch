# Codex Auth Switch v1.4.0

> 适配 Codex 26.1103.31037 的账号项目隔离：切换已保存账号时，默认沿用本机的普通目录项目。关联并修复 [#5](https://github.com/Mintimate/codex-auth-switch/issues/5) 中切换后项目列表不可见的问题。

## 新增与改进

- **切换时沿用本地项目**：将原账号的普通本地目录项目及排序合并到目标账号，保留目标账号已有项目，按项目 ID 或相同目录集合去重；原账号的项目列表保留。
- **可控制的沿用开关**：默认开启，可在切换弹窗或设置中关闭。切换结果显示新增及跳过数量，并将项目沿用失败与账号切换、客户端启动结果分别说明。
- **退出后备份并写入**：需要新增项目时，须先完全退出 Codex，或选择“切换并重启”。写入前保存原始配置备份；无法确认身份、配置结构异常、备份失败或检测到配置被修改时，停止对应操作并提示。
- **保留账号隔离边界**：云端绑定、冲突及未知结构的项目会跳过；不会修改会话正文、会话数据库或模型提供商配置。旧版没有账号分区的项目配置保持原样。
- 账号切换说明支持展开与收起，完善 CNB 镜像的自动发布流程。

## 使用说明

1. 从项目列表齐全的账号开始，结束 Codex 中正在执行的任务。
2. 在 Codex Auth Switch 中切换到另一个已保存账号，保留“切换时沿用本地项目”，选择“切换并重启”。
3. 重开 Codex 后检查项目列表；重复切换只补齐缺少的项目，不会覆盖目标账号已有项目的名称。

项目沿用目前支持可安全确认退出状态的 macOS / Windows 默认 Codex 目录。Linux、自定义目录或无法识别客户端时，可关闭此选项继续切换账号。设备码登录和 Auth 导入不执行项目沿用；本地 Codex 登录保存账号后的主动切换支持此功能。

备份保存在本应用账号库同目录的 `codex-project-state-backup.v1.json`，仅保留最近一次原始快照，最多 32 MiB；可能含私密界面状态，请勿公开分享。此功能按次合并项目入口，删除与重命名不会持续双向同步。

本次适配属于本地兼容实现，后续 Codex 版本可能需要更新。macOS 本地测试包已完成实际账号切换验收；各平台安装包由发布流水线构建。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
