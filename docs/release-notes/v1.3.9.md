# Codex Auth Switch v1.3.9

> 修复新版 macOS Codex 的额度查询兼容性，并在 Token 用量未能更新时保留旧数据、说明原因和更新时间。

## 修复与改进

- **适配新版 Codex 安装路径**：支持 macOS 上 ChatGPT / Codex 应用内新版嵌套的 Codex 程序位置，同时保留旧路径和自定义路径。某个候选程序无法启动时继续尝试其他位置，修复官方客户端仍有数据、切换器却无法获取每日 Token 用量的问题。
- **保留 Token 用量**：额度兼容查询成功但 Token 用量未更新时，保留本次运行中该账号上次成功查询的用量及原更新时间，额度百分比和重置次数继续更新；恢复后自动替换旧数据并清除提示。
- **明确显示部分查询失败**：订阅额度、账号详情与订阅价值模拟增加未更新原因、缓存标记和时间提示。没有旧数据时显示暂不可用，不把缺失用量当成零。
- **修复 Linux AppImage 启动权限**：修正打包时内部 AppRun 的执行权限，并在发布前验证最终 AppImage 的权限与启动窗口；统一 AppImage 产物命名，补充 Linux 安装兼容性说明。

## 升级提醒

- 升级后在“订阅额度”点击“刷新额度”，重新获取每日 Token 用量。旧用量保留在当前应用进程内，重启后需要重新查询。
- Linux 安装包以 Ubuntu 22.04 为构建基线，需要 glibc 2.35 或更新版本；Ubuntu 20.04、Debian 11 不在当前支持范围内。AppImage 下载后仍需赋予执行权限，例如 `chmod +x ./Codex-Auth-Switch_*.AppImage`。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
