# 版本说明

发布工作流会优先读取与标签同名的版本说明，例如：

```text
docs/release-notes/v0.8.0.md
```

文件存在时，GitHub Release 会原样使用它，CNB Release 也会同步相同正文。适合像 CC Switch 一样，为重要版本补充背景、重点功能、升级提醒和截图。

如果没有对应文件，工作流会根据 Conventional Commits 自动生成结构化中文说明，包括：

- 最多五项重点内容
- 新功能、修复、优化与调整、工程与文档等分类
- 分平台安装包选择
- GitHub 与 CNB 发布入口
- 发布日期与完整变更链接

建议手写版本说明保留以下结构：

```markdown
# Codex Auth Switch vX.Y.Z

> 一句话概括本次版本。

## 重点内容

- 用户最值得关注的变化

## 变更内容

### 新功能

- 功能说明

### 修复

- 修复说明

## 升级提醒

- 必要时说明兼容性、迁移或平台限制

## 下载与安装

- 列出本版本对应的安装包和官方发布渠道
```
