# Codex Auth Switch v1.1.9

> 优化多账号订阅额度查看与统计，保留每日 Token 活跃度，并精简页面与实现。

## 重点内容

- 订阅额度改为紧凑账号列表，每页显示 8 个账号，支持搜索、状态筛选和按额度、恢复时间、用量、重置次数排序。
- 顶部汇总订阅账号数、近 7 天和近 30 天 Token 用量、可用完整重置次数，并标明数据覆盖范围；缺失数据不再被当作零。
- 主页面保留每日 Token 活跃度热力图，支持全部账号汇总或单账号查看；方格随可用宽度自适应，减少右侧留白。
- 账号详情按需打开，额度窗口与用量统计分为两个页签，支持在详情内切换账号；恢复时间轴默认折叠。

## 修复与可靠性

- 统一每日用量的数据校验与去重规则，避免重复日期导致汇总数字和热力图不一致；同一订阅的多个本地档案不会重复计入汇总。
- 优化中文大数值显示、窄窗口布局、热力图边缘提示和详情键盘导航。
- 保留刷新失败时的上次成功数据与错误提示，账号搜索和详情继续遵循私密模式。
- 清理旧额度页面未使用的组件、样式、动画及文案，增加统计一致性测试。

## 升级提醒

- 本版本无需迁移账号数据，继续保持纯本地运行，不新增遥测或后端服务。
- 近 7 天、近 30 天及每日用量基于返回的账号用量数据，按 UTC 日期统计，不代表订阅额度百分比或 API 账单。
- 额度查询继续通过 Codex App Server 与 ChatGPT 兼容性层实现，不将这些端点视为有稳定性保证的公开 API。

## 下载与安装

- 支持应用内更新，也可下载对应平台安装包覆盖安装。
- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
