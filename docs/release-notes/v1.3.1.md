# Codex Auth Switch v1.3.1

> 修复普通界面可选中文字、触发复制粘贴等编辑操作的问题。

## 修复

- 普通界面不再响应鼠标拖动或双击选词，避免操作时出现文字选中高亮。
- 在输入框之外拦截 Command / Ctrl 的全选、复制、剪切、粘贴、撤销与重做快捷键，并处理系统菜单触发的剪贴板与文字选择操作。
- 搜索、账号重命名、代理地址等输入框保留正常的文字选择和编辑功能；验证码复制、一次性迁移 Auth 等专用操作继续正常工作。

## 升级提醒

- 本版本无需迁移账号数据，支持应用内更新或下载安装包覆盖安装。
- 继续保持纯本地运行，不新增遥测或后端服务。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
