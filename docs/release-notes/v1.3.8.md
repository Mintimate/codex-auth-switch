# Codex Auth Switch v1.3.8

> 改进 Windows 切换账号后的自动重启，新增实验性启动修复，并简化订阅价值模拟、补齐主要页面操作指引。

## 新功能

- **Windows 启动修复**：遇到“该进程没有程序包标识符”等启动错误时，可在“实验室 → Windows 启动修复”检测 Codex 安装，确认版本后点击“修复并打开”，重新注册当前用户的启动入口并尝试打开 Codex。
- **页面操作指引**：账号、订阅额度、Token 用量、订阅价值与 Codex 配置页面新增或完善首次使用指引，按页面状态说明主要操作，进度保存在本机。

## 修复与改进

- Windows“切换并重启”根据安装类型选择启动方式：商店／MSIX 版通过 Windows 应用激活机制重开，确认没有包身份的普通安装版才直接启动程序，避免因启动方式不匹配而缺少包身份。
- 无法确认客户端身份或包注册状态时，在退出客户端和写入凭据前停止自动重启；启动后增加进程身份核对与持续运行检查，减少误报成功。
- 订阅价值模拟改为更直观的单页操作：选择账号、参考模型和任务场景即可实时查看估算，高级比例调整与费用拆分按需展开。
- 改进空状态、查询失败提示及引导高亮，修复诊断日志按钮的图标对齐。

## 使用提醒

- 启动修复仅适用于可唯一确认的 Codex 商店／MSIX 安装。操作前请保存任务并完全退出 Codex，包括启动报错窗口；检测过期、入口不明确或进程仍在运行时不会执行修复。
- 修复保留账号与应用数据，不重置应用、不修改认证文件。它不能修复所有启动错误；安装文件缺失等情况仍需使用 Windows 应用修复或原安装渠道。
- macOS 和 Linux 仅显示“仅 Windows 可用”提示，不提供检测或修复操作；在线预览也不会执行检测或修复。
- 检测到 Codex 进程不代表窗口已恢复正常或账号已生效，请在 Codex 中确认。Windows 实机验证范围与待验证步骤见 [兼容性验证说明](https://github.com/Mintimate/codex-auth-switch/blob/v1.3.8/docs/windows-restart-validation.md)。
- 订阅价值模拟按所选模型与场景假设换算 API 费用，结果不是订阅账单，也不等于实际节省金额。

## 下载与安装

- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
