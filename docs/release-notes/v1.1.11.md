# Codex Auth Switch v1.1.11

> 用量价值模拟新增任务场景预设、可调缓存比例与费用拆分，方便理解和调整估算结果。

## 重点内容

- 新增“编程多轮”“通用多轮”“新任务／少复用”预设，一键设置输入占比和输入缓存比例，作为不同工作方式的试算起点。
- 默认采用“编程多轮”假设：输入占比 99%、输入缓存比例 90%；通用多轮为 90% / 50%，新任务／少复用为 80% / 0%。这些比例不是任务平均值或账号实测结果。
- 输入占比和输入缓存比例均可通过滑块或数字输入调整，支持 0.1% 步长，并与零缓存情景对比。
- 分别展示普通输入、缓存输入和输出的 Token 数与费用，更容易看出估算金额由哪一部分产生。

## 统计与说明

- 补充缓存比例的含义与使用建议：缓存比例以输入 Token 为分母，输出费用不享受缓存折扣。
- 提供官方缓存说明链接，明确多轮 Agent 超过 90% 的缓存命中率属于特定部署示例，不代表编程或通用任务的平均水平。
- 完善缺少缓存单价时的边界处理：只有假设缓存输入量大于零时，当前缓存情景才无法估算；普通输入、纯输出及零缓存情景仍可按对应单价计算。

## 升级提醒

- 本版本无需迁移账号数据，继续保持纯本地运行，不新增遥测或后端服务。价格更新仅请求公开文档，不上传账号凭据或用量。
- 账号每日用量仍只有 Token 总数。参考模型、输入占比和输入缓存比例均为模拟假设，结果不代表实际订阅收费或 API 账单。
- 近 7 天和近 30 天的汇总按包含今天的 UTC 自然日计算。模拟采用当前标准短上下文单价，不包含长上下文、快速模式、缓存写入、工具调用、税费及折扣。

## 下载与安装

- 支持应用内更新，也可下载对应平台安装包覆盖安装。
- macOS：按设备选择 Apple Silicon 或 Intel 的 DMG；Windows：选择 x64 EXE 或 MSI；Linux：选择 x64 AppImage、Deb 或 RPM。
- `.app.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，手动安装无需下载。
